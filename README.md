Direktori rental PS

Fitur untuk owner:
Registrasi dan login
dashnoard untuk mengelola jadwal, unit konsol, daftar harga, titik koordinat, daftar game, tambahkan foto tempat rental.

Fitur pengunjung:
Cari tempat rental berdasarkan nama tempat, judul game, unit ps.
Melihat detail dari tempat rental yang mencakup jadwal, unit konsol, daftar harga, titik koordinat, daftar game, foto tempat Rental.
Navigasi rute langsung ke tempat rental dengan google map direction URL

Teknologi yang digunakan:
PHP, MYSQL, BOOTSTRAP, leaflet.js, openstreetmap

cara instalasi lokal XAMPP
 1. clone repositori ini ke folder htdocs
 2. buka http://localhost/phpmyadmin
 3. buat data base baru lalu import file rental_console.sql
 4. sesuikan koneksi database default XAMPP: host 127.0.0.1, user root, password kosong
 5. Nyalakan Apache dan MySQL di XAMPP, lalu buka http://localhost/aplikasi_pencarian_rental/
